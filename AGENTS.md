# AGENTS.md

## Project scope
This project develops and improves Femme Fusion's website, marketing, and social media.

## Tech and structure
- Tech stack: Vue 3, Nuxt 3, Composition API, script setup, SASS.
- Images: use `<NuxtImg>` with descriptive `alt`.
- CTA buttons: short and clear, for example "Boka nu", "Skicka förfrågan".
- Copy and SEO: Swedish, ready to use on the website.
- SEO: correct heading levels, use `<strong>` for key words, add FAQ schema where relevant.

## Social media
- Language: Swedish.
- Start with a short, punchy hook. End with a booking CTA like "Boka oss idag!" or "Skicka förfrågan nu".
- Avoid long dashes (–). Use sentence breaks, commas, or periods instead.
- Hashtags are lowercase, mostly in English for Instagram, for example `#burlesque #danceclass`.
- Tone: inspiring, light, professional. Vary between informative and playful.
- Emojis are welcome in social posts.

## Tone and brand
Femme Fusion is a show group offering entertainment, song, and dance for parties, dinners, and events. Performances blend multiple dance styles with inspiration from burlesque. The goal is to create magic and a unique, memorable experience.

### How we want to be perceived
- Sophisticated, concrete, professional, luxury and elegance, talented.

### Communication style
- Warm, clear, and concrete. We sound human.
- Avoid quotation marks used as dashes and avoid long dashes (–) in sentences.
- Use short hyphens only when Swedish rules require it, for example "1900-tal", "VM-kval".
- Use correct Swedish with simple words.
- Prefer short, descriptive stories to paint a picture.
- Avoid fragmented, staccato sentences meant only to evoke mood.
